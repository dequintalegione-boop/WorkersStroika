# WorkersStroika — БригадаУчёт

## Локальный запуск на Windows

Приложение можно запускать полностью локально — без публикации на сайте и без подключения к облачному серверу. Данные приложения хранятся в локальном хранилище браузера на этом компьютере.

### Первый запуск

1. Установите Node.js 22 или новее.
2. Откройте папку проекта.
3. Дважды нажмите `start-local.bat`. Скрипт установит зависимости при необходимости, соберёт production-версию и откроет приложение.
4. Адрес локального приложения: **http://127.0.0.1:4173/**.

Окно терминала с локальным сервером должно оставаться открытым, пока вы пользуетесь приложением. Для остановки сервера нажмите `Ctrl+C` в этом окне.

Также можно запустить вручную из терминала VS Code Insiders:

```powershell
npm ci
npm run local
```

### Установка отдельного приложения

Сначала запустите локальную версию и откройте адрес `http://127.0.0.1:4173/` в Chrome или Edge. В меню браузера выберите установку страницы как приложения. После установки запускайте именно ярлык локального приложения.

Локальная версия отличается от установленного ранее сайта: адрес сайта и адрес `127.0.0.1` — разные источники. Данные между ними автоматически не переносятся. Перед переходом экспортируйте JSON-резервную копию в старом приложении и импортируйте её в локальном.

### Обновление приложения

В терминале из папки проекта выполните:

```powershell
git pull --ff-only origin main
npm ci
npm run local
```

Если локальный сервер уже работает, сначала остановите его сочетанием `Ctrl+C`. Затем выполните команды обновления и запустите локальную версию снова. Откройте приложение по адресу `http://127.0.0.1:4173/`.

### Важно о данных

- Локальная версия не синхронизирует данные с установленным веб-сайтом или другими компьютерами.
- Не очищайте данные сайта для адреса `127.0.0.1` в настройках браузера: там хранится база приложения.
- Регулярно создавайте JSON-резервную копию в разделе «Данные».
- Сборка и запуск не удаляют и не перезаписывают данные браузера.

### Обновление темы X-Analytics
Третья тема хранится под ключом `modern-dark`, но называется X-Analytics. При выборе она меняет не только палитру: ширину и структуру боковой панели, бренд-блок, верхнюю панель и карточки контента.
Service Worker обновлён до версии `brigade-tracker-v5`; статические файлы теперь загружаются по схеме network-first, чтобы установленное PWA не удерживало старые CSS/JS-бандлы.
После `git pull` остановите локальный сервер через `Ctrl+C`, снова запустите `npm run local` и откройте `http://127.0.0.1:4173/`. Не удаляйте локальные данные приложения.
